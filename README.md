# Button Click Counter App

A simple Android application that tracks and displays the number of times a button is clicked. Built as part of the Android Development Track (Task 5).

## 📌 Objective
Demonstrate the implementation of click listeners (`setOnClickListener`) and dynamically update text elements in an Android UI.

## 🛠️ Tools & Technologies Used
* **IDE:** Android Studio
* **Language:** Kotlin
* **UI Layout:** XML

## 🚀 Features
* Clean vertical layout containing a display label and action button.
* On-click event handler that increments the counter variable.
* Real-time text update on screen for every button press.

## 📁 Key Files
* `activity_main.xml` — Layout file defining UI components (`TextView` and `Button`).
* `MainActivity.kt` — Kotlin source file containing the logic and click listener.
